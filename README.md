# 🧳 W&T Job Finder

Сайт для поиска работодателей на **Summer Work and Travel USA 2027** по всем штатам и городам Америки.

- 🔎 **Поиск по штату и городу.** Выбираешь город (автодополнение или один из ~100 классических W&T-курортов), радиус и тип работы. Сайт находит отели, рестораны, фастфуд, кафе, парки развлечений, кемпинги, сувенирные магазины и т.д. Режим «Весь штат» показывает все заведения штата с публичным email.
- ✅ **Только работа, подходящая под W&T.** Категории подобраны по правилам Госдепа США ([22 CFR 62.32](https://www.ecfr.gov/current/title-22/chapter-I/subchapter-A/part-62/subpart-B/section-62.32)). Каждое место помечается: «Подходит», «Уточнить» (бары, казино, спа) или «Не подходит» (детские сады, клиники, кадровые агентства, склады и т.п.).
- 🗺️ **Google Maps.** У каждого заведения есть кнопка «Google Maps» (отзывы, фото, сайт) и «Посмотреть» (карта Google прямо на сайте). Слева есть быстрые ссылки «искать отели / рестораны / … в этом городе в Google Maps» и ссылки на Indeed, Google Jobs, CoolWorks, LinkedIn.
- 🏙️ **Выбор города без ошибок.** При выборе штата загружается список всех его городов и посёлков. Нажми на поле «Город»: сверху W&T-курорты, ниже города по населению. При вводе список фильтруется.
- 🏠 **Жильё.** Курорты, где работодатели часто дают жильё (острова, нацпарки, Аляска, Cedar Point, Wisconsin Dells и др.), помечены 🏠, по ним есть фильтр. В результатах есть фильтр «чаще дают жильё» (отели, курорты, кемпинги, парки). Письма сами спрашивают про жильё (для двоих в режиме «вдвоём»). В трекере для каждого места отмечается «даёт / помогает найти / нет» и цена в неделю, а если работодатель упомянул жильё в ответе, сайт это заметит. В карточке места есть ссылки «Жильё рядом с работой».
- 🗺️ **Большая карта** с кнопкой «на весь экран» и легендой. Нажми на точку: откроется карточка с кнопками Google Maps, «Посмотреть», «Написать», «Сохранить».
- 👭 **Поиск вдвоём.** В профиле выбери «Вдвоём с подругой / другом»: письма пишутся от «we», подписаны обоими именами, с контактами обоих и ссылкой на общее резюме. Подругу можно ставить в копию, чтобы ответ видели оба. Контактами делитесь через «Бэкап JSON» → «Импорт»: статусы и заметки объединяются.
- ✉️ **Письма через Gmail, даже если вакансий нет.** Готовые английские шаблоны: холодное письмо, отклик на вакансию, напоминание. Данные из профиля подставляются сами. Кнопка открывает Gmail с готовым письмом, остаётся только нажать «Отправить».
- 🚀 **Рассылка по очереди.** Письма открываются одно за другим: отправил, отметил, открылось следующее. Через 7 дней кнопка «Пора напомнить» собирает тех, кто не ответил.
- 📋 **Трекер.** Статусы (отправлено → ответили → интервью → оффер), заметки, экспорт в CSV и бэкап в JSON.
- 📧 **Поиск email на сайтах** (на Vercel или с локальным сервером). Сервер сам заходит на сайт заведения, страницы Contact и Careers и достаёт email.

Профиль, шаблоны и контакты хранятся **только в твоём браузере** (localStorage), в репозиторий ничего не попадает. Делай бэкап JSON время от времени.

## Как запустить

### Вариант 1. Vercel (рекомендую, бесплатно, полная версия)

Сайт и сервер (функции в `api/`) работают на Vercel без настройки. Каждый push в репозиторий деплоится автоматически.

1. Зайди на [vercel.com/new](https://vercel.com/new) через GitHub (Continue with GitHub).
2. **Import Git Repository** → `Nurches/search-offer` → **Import**.
3. Ничего не меняй (Framework Preset: Other, настройки берутся из `vercel.json`) → **Deploy**.
4. Через ~30 секунд будет адрес вида `https://search-offer-xxxx.vercel.app`.

Чтобы включить поиск через Google, добавь ключ: Project → **Settings → Environment Variables** → `GOOGLE_MAPS_API_KEY`, затем **Deployments → … → Redeploy**.

### Вариант 2. На своём компьютере

Нужен [Node.js](https://nodejs.org) 18 или новее. Зависимостей нет, `npm install` не нужен.

```bash
git clone https://github.com/Nurches/search-offer.git
cd search-offer
npm start                                   # http://localhost:3000
GOOGLE_MAPS_API_KEY=твой_ключ npm start     # с поиском через Google
```

### Вариант 3. GitHub Pages (только статика)

Repo → **Settings → Pages → Source: GitHub Actions**, затем запусти workflow `Deploy site to GitHub Pages`. Работает всё, кроме автоматического поиска email на сайтах и Google Places. Адрес сервера (например, Vercel) можно указать во вкладке «Письмо и профиль → Сервер».

## Ключ Google (необязательно)

Без ключа сайт ищет через OpenStreetMap: бесплатно, но знает не все заведения. Ссылки «Google Maps» и встроенная карта Google работают **без ключа**. Ключ нужен только для поиска заведений через Google Places, где есть почти всё.

**Какой ключ:** API key для **Places API (New)**.

1. [console.cloud.google.com](https://console.cloud.google.com/) → создай проект.
2. Подключи платёжный аккаунт (Billing). Google требует карту даже для бесплатного лимита.
3. **APIs & Services → Library → Places API (New) → Enable**.
4. **APIs & Services → Credentials → Create credentials → API key**.
5. В настройках ключа: **API restrictions → Restrict key → Places API (New)**. Ограничение по сайту (referrer) не нужно: ключ хранится на сервере и в браузер не попадает.
6. Защита от счетов: **Places API (New) → Quotas** → лимит `SearchTextRequest` в день, например 30. Тогда больше этого числа запросов просто не пройдёт.

**Бесплатный лимит.** С марта 2025 года у Google нет общего кредита $200, вместо него бесплатный месячный лимит на каждый тип запроса. Сайт запрашивает сайт, телефон и рейтинг заведения, поэтому запрос относится к уровню **Text Search Enterprise**: около **1 000 бесплатных запросов в месяц**, дальше платно (порядка $35 за 1 000). Один запрос = одна категория (до 20 мест). Поиск по 8 категориям = 8 запросов, то есть примерно **120 поисков в месяц бесплатно**. Цены и лимиты меняются, сверяйся с [официальной страницей](https://developers.google.com/maps/billing-and-pricing/pricing).

`GOOGLE_MAX_PAGES` (1–3, по умолчанию 1): сколько страниц по 20 мест брать на категорию. Больше страниц — больше результатов, но и запросов.

## Рассылка в один клик и отслеживание ответов (Gmail API)

Без настройки сайт открывает Gmail с готовым письмом, отправляешь сам. После подключения Gmail API:

- **📨 «Отправить всем»** / **«Написать всем выбранным»**: сайт сам отправляет письма с твоего Gmail, каждое лично на адрес заведения. Пауза 1–1,5 минуты между письмами и дневной лимит (по умолчанию 40), чтобы Google не счёл это спамом. Вкладку держи открытой.
- **🔄 Отслеживание ответов**: сайт запоминает ветку каждого письма и проверяет её (каждые 10 минут, пока сайт открыт, или кнопкой «Проверить ответы»). Ответившие получают статус «Ответили», в трекере виден текст ответа и ссылка на переписку. Недоставленные письма помечаются «Email не дошёл».
- **🔁 «Напомнить всем»**: через 7 дней без ответа отправляет напоминание в ту же ветку.

Настройка (один раз, в том же Google Cloud проекте):

1. **APIs & Services → Library → Gmail API → Enable.**
2. **Google Auth Platform → Branding**: название приложения (например, W&T Job Finder) и твой email.
3. **Audience**: External, оставить режим **Testing**, в **Test users** добавить свой Gmail (и подруги, если она будет отправлять со своего).
4. **Clients → Create client → Web application**. В **Authorized JavaScript origins** добавить адрес сайта на Vercel (например, `https://search-offer.vercel.app`) и, для локального запуска, `http://localhost:3000`.
5. Скопировать **Client ID** и добавить в Vercel переменную `GOOGLE_OAUTH_CLIENT_ID` (Redeploy). Либо вставить на сайте: «Письмо и профиль → Сервер → Gmail API».
6. На сайте: «Мои контакты» → **🔐 Подключить Gmail**. Google покажет «приложение не проверено». Для личного приложения это нормально: «Дополнительно → Перейти». Разреши отправку и чтение писем.

Сайт использует разрешения `gmail.send` (отправка) и `gmail.readonly` (только чтобы видеть ответы в ветках своих писем). Токен хранится только в памяти вкладки и не уходит на сервер. Вход нужно повторять в каждой новой сессии.

## Как пользоваться: план на сезон

1. **Профиль** («Письмо и профиль»): имя латиницей, университет, даты, ссылка на резюме в Google Drive (доступ «все, у кого есть ссылка»). Если в браузере несколько Gmail-аккаунтов, укажи нужный.
2. **Курорты**: выбери направление (Ocean City, Wildwood, Mackinac Island, Yellowstone, Wisconsin Dells…) → «Искать здесь».
3. Отметь подходящие заведения → «➕ В мои контакты».
4. **Мои контакты** → «📨 Отправить всем» (с Gmail API) или «🚀 Рассылка по очереди» (вручную). Не больше 30–50 писем в день с одного Gmail.
5. Ответы сайт отметит сам (с Gmail API). Через неделю жми «🔁 Напомнить всем».
6. Перед согласием на оффер пройди чек-лист во вкладке «Правила W&T» и отправь оффер в ЦМО / InterExchange на проверку.

## Разработка

```
public/            статический сайт (HTML + ES-модули, без сборки)
  js/data.js       штаты, категории работ, W&T-курорты, правила-флаги
  js/search.js     OpenStreetMap (Overpass), геокодинг, оценка «подходит ли под W&T»
  js/outreach.js   шаблоны писем, ссылки Gmail / Google Maps / сайты вакансий
  js/gmail.js      Gmail API: вход Google, отправка, разбор ответов и недоставленных писем
  js/app.js        интерфейс
api/               функции Vercel (тонкие обёртки над server/handlers.js)
server/            Node-сервер без зависимостей
  handlers.js      API: /api/health, /api/emails, /api/overpass, /api/places
  emails.js        поиск email на сайтах (с защитой от SSRF)
  places.js        Google Places API (New)
test/              юнит-тесты (node --test) и e2e-тест в Chromium
```

```bash
npm test          # юнит-тесты
npm run test:e2e  # браузерный тест (нужен Playwright)
```
